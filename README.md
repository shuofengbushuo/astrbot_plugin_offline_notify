# AI下线通知系统

定时向QQ群发送AI服务下线提醒，支持自定义通知内容、多群组、差异化时间等。

## 功能概览

| 功能 | 说明 |
|------|------|
| 定时通知 | 基于 APScheduler 实现精确到分钟的定时触发 |
| 差异化时间 | 工作日、周末、特定日期可设置不同的下线时间 |
| 多群组通知 | 同时向多个QQ群发送下线提醒 |
| 自定义模板 | 标题、正文、表情符号、底部文字均可自定义 |
| 通知预览 | WebUI 和命令均可预览通知消息效果 |
| 失败重试 | 消息发送失败自动重试，间隔递增 |
| 自我监控 | 心跳检测调度器状态，异常时自动告警 |
| 告警双通道 | 支持向QQ群或QQ私聊发送告警信息 |

## 快速开始

1. 在 AstrBot WebUI 的「插件管理」中启用本插件
2. 在插件配置中填写**目标通知群组**的 QQ 群号
3. 根据需要调整**定时通知计划**中的下线时间
4. 使用 `/下线通知 预览` 命令确认消息效果
5. 使用 `/下线通知 测试` 命令向当前群发送一条测试通知

## 配置说明

### 基础配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 启用下线通知 | 开关 | 开启 | 关闭后将停止所有定时通知，但插件仍保持运行 |
| 提前通知时间 | 整数 | 5 | 在下线前 N 分钟发送通知，范围 1-30 分钟 |

---

### 定时通知计划

每个计划控制一组特定日期的下线通知行为。默认包含两个计划：

#### 默认计划

| 计划名称 | 日期类型 | 下线时间 | 提前通知 | 状态 |
|----------|----------|----------|----------|------|
| 工作日下线 | 工作日（周一至周五） | 23:00 | 5 分钟 | 启用 |
| 周末下线 | 周末（周六、周日） | 23:20 | 5 分钟 | 启用 |

#### 计划字段说明

| 字段 | 类型 | 允许值 | 说明 |
|------|------|--------|------|
| `name` | 文本 | 任意字符串 | 计划名称，用于日志和状态显示，便于区分不同计划 |
| `day_type` | 下拉选择 | `everyday`（每天）、`weekday`（工作日）、`weekend`（周末）、`specific`（特定日期） | 决定该计划在哪些日期生效 |
| `specific_days` | 多选列表 | `monday`、`tuesday`、`wednesday`、`thursday`、`friday`、`saturday`、`sunday` | 仅当 `day_type` 为 `specific` 时生效，选择具体的星期几 |
| `offline_time` | 文本 | 24小时制 `HH:MM` 格式，如 `22:30`、`23:00`、`00:00` | 设定的AI下线时间，通知将在该时间前 N 分钟发出 |
| `advance_minutes` | 整数 | 1-30 | 提前通知的分钟数，覆盖全局设置。例如设为 10，则在下线时间前 10 分钟发送 |
| `enabled` | 开关 | 开启 / 关闭 | 启用或禁用该计划。禁用后该计划不会创建定时任务 |

#### 配置示例

**示例 1：每天 22:00 下线，提前 10 分钟通知**

```json
{
    "name": "每日下线",
    "day_type": "everyday",
    "offline_time": "22:00",
    "advance_minutes": 10,
    "enabled": true
}
```

**示例 2：仅在周一、周三、周五 23:30 下线**

```json
{
    "name": "隔日下线",
    "day_type": "specific",
    "specific_days": ["monday", "wednesday", "friday"],
    "offline_time": "23:30",
    "advance_minutes": 5,
    "enabled": true
}
```

**示例 3：工作日 22:30 下线，周末 23:20 下线**

```json
[
    {
        "name": "工作日下线",
        "day_type": "weekday",
        "offline_time": "22:30",
        "advance_minutes": 5,
        "enabled": true
    },
    {
        "name": "周末下线",
        "day_type": "weekend",
        "offline_time": "23:20",
        "advance_minutes": 5,
        "enabled": true
    }
]
```

### 消息模板

消息模板控制通知消息的外观和内容。支持使用 `{变量名}` 插入动态内容。

#### 标题模板

**说明**：通知消息的标题行，通常用方括号包裹以突出显示。

**可用变量**：

| 变量 | 说明 | 示例值 |
|------|------|--------|
| `{time}` | 下线时间 | `23:00` |
| `{date}` | 当前日期 | `2026-07-07` |
| `{day_of_week}` | 星期几（中文） | `周二` |
| `{countdown_minutes}` | 剩余分钟数 | `5` |

**默认值**：`【AI服务下线通知】`

**使用示例**：

| 模板内容 | 渲染结果 |
|----------|----------|
| `【AI服务下线通知】` | `【AI服务下线通知】` |
| `【{day_of_week}下线提醒】` | `【周二下线提醒】` |
| `【{date} AI下线】` | `【2026-07-07 AI下线】` |

---

#### 正文模板

**说明**：通知消息的主体内容，是群成员看到的核心信息。

**可用变量**：

| 变量 | 说明 | 示例值 |
|------|------|--------|
| `{time}` | 下线时间 | `23:00` |
| `{date}` | 当前日期 | `2026-07-07` |
| `{day_of_week}` | 星期几（中文） | `周二` |
| `{countdown_minutes}` | 剩余分钟数 | `5` |
| `{emoji}` | 用户配置的表情符号 | `🌙` |

**默认值**：

```
各位成员请注意~

{emoji} AI助手即将在 {time} 下线休息，预计还有 {countdown_minutes} 分钟。

如有需要请尽快处理未完成的事项。
明天见！晚安~
```

**渲染示例**（假设当前为周二 22:55，下线时间 23:00）：

```
各位成员请注意~

🌙 AI助手即将在 23:00 下线休息，预计还有 5 分钟。

如有需要请尽快处理未完成的事项。
明天见！晚安~
```

**自定义示例**：

| 模板内容 | 渲染结果 |
|----------|----------|
| `晚安！AI将在 {time} 休息~` | `晚安！AI将在 23:00 休息~` |
| `{emoji} 还有 {countdown_minutes} 分钟就下线啦！` | ` 还有 5 分钟就下线啦！` |
| `今天是 {day_of_week}，{time} 准时下线哦~` | `今天是 周二，23:00 准时下线哦~` |

---

#### 表情符号

**说明**：用于正文中 `{emoji}` 变量的替换值，可以是任意 Unicode 表情符号。

**默认值**：`🌙`

**常用推荐**：

| 符号 | 含义 |
|------|------|
| `🌙` | 月亮（晚安） |
| `😴` | 睡觉 |
| `💤` | 休息 |
| `🌟` | 星星 |
| `👋` | 再见 |

---

#### 底部模板（可选）

**说明**：通知消息底部的附加信息，留空则不显示。可用变量与正文模板相同。

**默认值**：（空，不显示）

**使用示例**：

| 模板内容 | 渲染结果 |
|----------|----------|
| `—— AI助手 · {date}` | `—— AI助手 · 2026-07-07` |
| `明天 {time} 再见！` | `明天 23:00 再见！` |

### 目标群组

配置需要接收下线通知的QQ群列表。

| 字段 | 类型 | 说明 |
|------|------|------|
| `group_id` | 文本 | QQ群号，必填。请确保机器人已加入该群 |
| `group_name` | 文本 | 群名称备注，仅用于管理界面显示，不影响功能 |
| `enabled` | 开关 | 启用或禁用该群组的通知。禁用后该群不会收到通知 |

**注意**：如果未配置任何群组，通知将不会发送到任何地方。

---

### 重试配置

消息发送失败时的自动重试策略。

| 配置项 | 类型 | 默认值 | 允许范围 | 说明 |
|--------|------|--------|----------|------|
| 最大重试次数 | 整数 | 3 | 0-10 | 设为 0 则不重试。每次发送失败后自动重试，最多重试 N 次 |
| 重试基础间隔 | 整数（秒） | 10 | 5-120 | 实际等待时间 = 基础间隔 × 当前重试次数。例如基础间隔 10 秒，第 1 次重试等待 10 秒，第 2 次等待 20 秒，第 3 次等待 30 秒 |

---

### 自我监控配置

定时任务的健康检查和异常告警功能。

| 配置项 | 类型 | 默认值 | 允许范围 | 说明 |
|--------|------|--------|----------|------|
| 启用自我监控 | 开关 | 开启 | - | 关闭后不再进行心跳检测和告警 |
| 心跳检测间隔 | 整数（秒） | 300 | 60-3600 | 每隔 N 秒检查一次调度器是否正常运行 |
| 告警通知群号 | 文本 | 空 | - | 调度器异常时，向此 QQ 群发送告警消息。留空则仅记录日志 |
| 告警通知QQ号 | 文本 | 空 | - | 调度器异常时，向此 QQ 号发送私聊告警消息。留空则不发送私聊告警 |

**告警触发条件**：

1. 调度器未运行（插件启动失败或被意外停止）
2. 调度器心跳超时（超过 3 倍心跳间隔未更新）

**告警冷却机制**：同一异常不会重复告警，两次告警之间至少间隔 30 分钟，避免告警轰炸。

**双通道告警**：`告警通知群号` 和 `告警通知QQ号` 可同时填写，异常时会同时向群和私聊发送告警。也可以只填其中一个，实现单通道告警。

## 命令列表

| 命令 | 说明 | 使用场景 |
|------|------|----------|
| `/下线通知 状态` | 查看调度器运行状态、任务列表、下次触发时间 | 确认系统是否正常工作 |
| `/下线通知 预览` | 预览当前配置的通知消息实际效果 | 调整模板后确认显示效果 |
| `/下线通知 测试` | 手动向当前群发送一条测试通知 | 验证消息能否正常送达 |
| `/下线通知 统计` | 查看发送成功/失败次数、最近发送时间 | 排查发送问题 |

## WebUI 管理面板

在 AstrBot WebUI 中进入插件页面，可使用以下功能：

### 系统状态

实时显示调度器运行状态、定时任务数量、累计触发次数、成功/失败统计。点击「刷新状态」按钮更新数据。

### 消息预览

1. 设置模拟的下线时间和提前分钟数
2. 点击「生成预览」
3. 查看渲染后的完整通知消息效果

### 测试发送

1. 输入目标 QQ 群号
2. 点击「发送测试通知」
3. 确认该群是否收到通知消息

## 常见问题

### Q: 修改配置后不生效？

A: 修改 `_conf_schema.json` 中的默认值后，需要**重启 AstrBot** 才能生效。如果是在 WebUI 配置界面中修改，保存后也需要重启插件或 AstrBot。

### Q: 通知没有发送？

A: 按以下步骤排查：

1. 检查「启用下线通知」是否为开启状态
2. 检查「目标通知群组」中是否填写了正确的 QQ 群号
3. 检查对应群组的 `enabled` 开关是否为开启状态
4. 使用 `/下线通知 状态` 确认调度器是否正常运行
5. 使用 `/下线通知 测试` 手动发送测试通知

### Q: 如何只在工作日发送通知？

A: 在「定时通知计划」中，将工作日计划的 `day_type` 设为 `weekday`，将周末计划的 `enabled` 设为关闭即可。

### Q: 告警通知收不到？

A: 检查「自我监控配置」中的「告警通知群号」或「告警通知QQ号」是否已填写。注意：QQ号告警为私聊消息，需要确保机器人能与该用户私聊。

### Q: 支持哪些平台？

A: 目前支持 `aiocqhttp`、`qq`、`qq_official` 平台。
